## Method and limits

- **DONE** means: a commit exists on `main` at `e9913ae` whose diff implements the item, and a file
  in the tree implements it. The short SHA and the file are given. **It says nothing about whether
  the feature works in production, against the real Gratsi data, or at all** — there is no database,
  no Clerk, no R2 and no Meta credential on this machine, so nothing here was executed. Several
  DONE rows are features whose only runtime proof is a unit test on PGlite or a Playwright spec in
  demo mode.
- **PARTIAL** names the concrete missing piece: a file and what is absent from it.
- **NOT STARTED** names the file or route the work would land in.
- **UNCLEAR** is used where the item's wording does not determine an observable outcome (a
  constraint that forbids rather than builds, a process step, or a target the repo holds no record
  of). It is used in preference to guessing.
- Evidence came from `git log --oneline`, `git log -S"<symbol>"`, `git log --diff-filter=A -- <path>`,
  and reading `apps/web/src/app/app/<module>/`, `packages/db/src/`, `packages/domain/src/`,
  `apps/web/e2e/*.spec.ts`, `docs/decisions.md`, `docs/decisions/` and `docs/audits/`.
- `main` at `e9913ae` has absorbed GRID-01…06, VIEWS-01…04, LINK-01…03, EDIT-01…04, E2E-LIVE-01…03,
  FIX-SPEC-01…02 and the earlier PARITY-* series; those were checked before anything was called NOT
