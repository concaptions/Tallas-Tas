# Airtable → platform module gap audit (2026-10-01)

Ground truth: the **live Gratsi base `appllDG4OmkK2Hdnn`** (metadata fetched 2026-10-01 via the base-schema endpoint), not the template `appnaSGAgOUbJ0f9m`. Read-only audit; no code changed. Produced by five parallel auditors over `packages/db/src/schema`, `apps/web/src/app/app`, `apps/web/src/components/shell/nav.ts` and the importer, then compiled here.

## Summary

- **6 tables have no Drizzle table at all:** Creative Sheet, (Internal) Creative Modules, SM Campaign Management Feed, Email Campaigns Management, Email Flows Management, (Internal) Copy Type.
- **1 table is only partially modelled:** Creative Reporting → `ad_metrics`.
- **1 table has a Drizzle table but no page or nav entry:** Client Assets Organisation.
- **Themes was NOT modelled on Creative Modules** (evidence in §3). The template↔Gratsi table-ID swap is real and documented in §4; today's `airtable-fetch.ts`/`import-mappings.ts` key by the Gratsi IDs (verified: Concepts=102 / Angles=43 came through the right way round), so the risk is any future base that follows the template's IDs — Prompt 3 should resolve by table NAME.
- The importer today fetches 14 Gratsi tables and skips 7 (§5); four of its `SKIPPED_AIRTABLE_TABLES` entries are stale.
